Additional tasks

Along with caring for our cats and taking care of the shelter, you, as a volunteer, will also have to help the coordinators with some small miscellaneous tasks that will help keep the shelter in good shape. These will include the following:

Community events - from time to time, the coordinators will set up community events, and as a volunteer, you will be required to help them set up these events. Providing extra aid with these events can make them run faster and more smoothly.

Facility building and grounds - Along with keeping the shelter inside clean and tidy, the outside of the shelter will need to be kept in good condition, too. This will include, but not be limited to: mowing the grass outside the shelter, weed eating, and minor repairs that might need to be done.

Assisting with TNR/vet appointments - every now and then, the coordinators will need help with the TNR process for the cats. TNR stands for "trap, neuter, and return", and as a volunteer, you will have to help with trapping the cats so the coordinators can do the rest of the process. You will also have to aid in vet appointments for the cats from other rescues,
